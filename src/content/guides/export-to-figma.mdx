---
title: Export to Figma
description: Apply a tweakcn theme to the shadcncraft Figma UI kit so designs match your code.
---

**Export to Figma** connects tweakcn to [shadcncraft](https://shadcraft.com),
a paid Figma UI kit for shadcn/ui. The shadcncraft Figma plugin applies your
tweakcn theme to the kit components. tweakcn does not make a Figma file by
itself.

<Frame caption="The Export to Figma dialog.">
![Export to Figma dialog for tweakcn and shadcncraft](/images/figma-dialog.png)
</Frame>

## Before you begin

- A Figma account.
- A shadcncraft license. The dialog shows the current price.
- A finished theme in the editor. [Save it](/sharing/save-and-share) first, so
  you can open it again.

<Steps>
<Step title="Open the dialog">

In the tweakcn header, select **Export to Figma**.

</Step>
<Step title="Get the kit">

Select **Buy now** to buy shadcncraft, or **Preview Blocks** to see the kit in
Figma first. Download the kit and open it in Figma.

</Step>
<Step title="Open the plugin">

In Figma, run the shadcncraft plugin.

</Step>
<Step title="Apply your theme">

Use the plugin to import your tweakcn theme. The plugin updates the kit
components with your colors, radius, and fonts.

</Step>
</Steps>

<Note type="info" title="Not tested in these docs">
The plugin steps come from the tweakcn dialog. These docs did not test the
paid kit. See the shadcncraft documentation for the current plugin steps.
</Note>

## Without a paid kit

To use the colors in any Figma file, open **Code**, select hex as the color
format, and copy the values into Figma color styles.
