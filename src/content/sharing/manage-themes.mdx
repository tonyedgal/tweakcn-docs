---
title: Manage saved themes
description: Find, apply, edit, publish, and delete your saved tweakcn themes on the Your Themes page.
---

The **Your Themes** page lists every theme that you saved. Use it to open a
theme, publish it, change its tags, or delete it.

## Open the page

<Steps>
<Step title="Open your account menu">

Sign in. Select your avatar in the header, then select **Settings**.

</Step>
<Step title="Select Themes">

In the settings sidebar, select **Themes**. The page **Your Themes** opens at
[tweakcn.com/settings/themes](https://tweakcn.com/settings/themes).

<Frame caption="The Your Themes page with one saved theme.">
![Your Themes settings page with the theme Warm Ivory Coral](/images/your-themes.png)
</Frame>

</Step>
</Steps>

## Find a theme

- Type in **Search themes...** to filter by name.
- Use **Sort by** to sort: **Newest First**, **Oldest First**, or **Name (A-Z)**.

A published theme shows a **Published** label.

## Theme actions

Select **⋮** on a theme card to see these actions:

<Frame caption="The theme card menu. Delete Theme is at the bottom.">
![Theme card menu with Quick Apply, Open Theme, Edit Theme, Copy URL, Publish to Community, and Delete Theme](/images/your-themes-menu.png)
</Frame>

| Action | Result |
| --- | --- |
| **Quick Apply** | Loads the theme into the editor state. |
| **Open Theme** | Opens the public page of the theme. |
| **Edit Theme** | Opens the theme in the editor. |
| **Copy URL** | Copies the theme link. |
| **Publish to Community** | Lists the theme on the community page. See [Publish to the community](/sharing/publish). |
| **Edit Tags** | Changes the tags of a published theme. |
| **Unpublish from Community** | Removes the theme from the community page. The theme stays saved. |
| **Delete Theme** | Deletes the theme after a confirmation. |

<Note type="warning" title="Delete breaks the install URL">
After you delete a theme, its install URL and its public link stop working.
Projects that already installed the theme keep their CSS.
</Note>
