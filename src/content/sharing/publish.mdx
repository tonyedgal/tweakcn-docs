---
title: Publish to the community
description: List a saved tweakcn theme on the community page so other people can find and install it.
---

A published theme shows on the [community page](https://tweakcn.com/community).
Other people can open it and install it.

<Frame caption="The community page.">
![tweakcn community themes page](/images/community.png)
</Frame>

## Before you begin

- A [saved theme](/sharing/save-and-share).
- A check of both modes and the contrast. Other people install the theme as it is.

<Steps>
<Step title="Open the saved theme">

Load the saved theme in the editor. The top bar shows **Publish**.

</Step>
<Step title="Select Publish">

Select **Publish**. The dialog asks **Publish to the community?**

</Step>
<Step title="Add tags">

Add up to 5 tags, for example `warm`, `light`, `saas`. Tags help people find
the theme.

</Step>
<Step title="Confirm">

Confirm. The button changes to **Published**, and the theme shows on the community page.

</Step>
</Steps>

<Note type="info" title="Publish limit">
You can publish 5 themes in one hour.
</Note>
